# P0 ticket queue candidate
Migration 0012 is additive, no historical backfill. Machine endpoint POST /api/bot/ticket-queue accepts lease/renew/retry/ack with a distinct NEXORAID_TICKET_MACHINE_KEY (64 hex characters), not the actor key. Leases last 180 seconds; the consumer must renew before expiry, and renewal is fenced by the current unexpired token and active order state. Retries use bounded exponential backoff; acknowledgements preserve canonical ticket links and message IDs. Bot consumer integration, crash recovery, membership gating, portal sync display and live E2E remain open. Do not activate or declare stable before these gates.
