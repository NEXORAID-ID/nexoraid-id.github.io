# Web order ticket delivery
Migration 0007 queues new orders transactionally via a database trigger. No historical backfill. The existing bot API key and fixed guild authenticate machine-only ticket-sync endpoints; these do not impersonate a user. GET returns pending orders, POST acknowledges a channel/message pair or defers retry. One bot replica must process serially. Existing order permissions and claim endpoints are unchanged.
