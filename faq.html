9 pertanyaan

Bagaimana cara order?+

Pilih layanan di katalog dan buka halaman detail. Klik Order via Discord untuk masuk ke channel tiket resmi. Sampaikan request, lalu tunggu admin mengonfirmasi stok, harga final, metode pembayaran, dan estimasi proses.

Apakah bisa bayar langsung di website?+

Website ini adalah katalog layanan. Pembayaran dan komunikasi pesanan dilakukan melalui admin di tiket Discord resmi setelah detail dikonfirmasi.

Apakah harga sudah final?+

Harga katalog menjadi acuan. Stok, spesifikasi akun, kondisi perangkat, dan request dapat memengaruhi harga. Harga promo dapat berubah sewaktu-waktu. Admin mengonfirmasi harga final sebelum pembayaran.

Akun game apa saja yang tersedia?+

Tersedia kategori Random, Starter, Premium, dan Custom dengan harga Sesuai Request. Contoh: akun GTA, Steam, Epic Games, game mobile, game PC, starter, dan custom request. Ketersediaan serta harga menyesuaikan stok, spesifikasi akun, dan request customer.

GTA Legacy atau Enhanced?+

Layanan GTA Online berlaku untuk PC Legacy dan Enhanced dengan harga sama. Semua layanan via login akun. Money berasal dari hasil run heist, bukan drop money. Estimasi money bisa berbeda setiap run dan proses mengikuti cooldown akun. Beberapa layanan perlu dicek admin terlebih dahulu.

Apa yang termasuk lisensi Windows & Office?+

Windows 10/11 License Rp75.000, Microsoft Office License Rp75.000, dan Bundle Windows + Office Rp100.000. Stok dari admin/owner, termasuk panduan aktivasi serta support aktivasi basic. Pilihan produk Windows 7/8/10/11 dan Office 2016/2019/2021/365 dikonfirmasi ke admin; harga Windows 7/8 belum dicantumkan.

Berapa lama proses pesanan?+

Estimasi dikonfirmasi admin berdasarkan layanan, antrean, kondisi akun/perangkat, dan ketersediaan. Khusus GTA Online, proses juga menyesuaikan cooldown akun.

Bagaimana cara menjadi seller?+

Biaya pendaftaran seller Rp500.000 untuk akses harga khusus yang dapat dijual kembali. Slot terbatas. Buka tiket untuk konfirmasi ketersediaan dan ketentuan program.

Discord tidak langsung membuka channel, harus bagaimana?+

Pastikan sudah login ke akun Discord yang memiliki akses ke server dan channel NEXORAID. Jika channel belum dapat dibuka, hubungi admin NEXORAID melalui kontak yang sudah kamu miliki untuk meminta akses.
